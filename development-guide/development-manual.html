1. Architecture Overview #

CityTone is a single-file HTML5 Canvas application with zero external dependencies. It runs entirely in the browser — no build tools, no npm, no frameworks. The architecture follows a modular IIFE pattern:

LaunchPulse.html (749KB)
├── CityTone Player (P)        — main music player + city/galaxy visualizer
├── ToneSync Module            — audio analysis → morph target computation (IIFE)
├── JUNGLE Module              — jungle scene visualizer (IIFE, independent rAF loop)
├── UI Layer                   — playlist, controls, drag-drop
└── Boot/Hash Processing       — scene selection, test hooks
Key Design Principles
  • Single file: Everything in one HTML file for zero-friction deployment
  • IIFE modules: ToneSync and JUNGLE are self-contained IIFEs with clean public APIs
  • Independent rAF loops: JUNGLE runs its own requestAnimationFrame loop, decoupled from the main player
  • Error resilience: Both loops use try-catch with error counting — never kill the rAF chain
  • Pixel art: All visuals use fillRect with image-rendering:pixelated — no sprites, no images
  • Pre-allocated arrays: _freqBands, _riverCols, _ffPos are reused to avoid per-frame GC

3. Core Modules #

CityTone Player (P)

The main player object handles:

  • Audio playback: Web Audio API with AnalyserNode for real-time FFT
  • Frequency analysis: 8 normalized bands (0-1) stored in P._freqBands
  • Scene detection: 90-frame evaluation window analyzing energy, bass ratio, smoothness, dynamic range, beat presence
  • City rendering: 5 parallax layers, buildings, ships, ferris wheel, weather, seasons, easter eggs
  • Galaxy rendering: 400 stars, 14 solar systems, nebulae, scroll-zoom

Public API

window.player    // P — the main player object
window.JUNGLE    // JUNGLE module — dev/test access

// JUNGLE public API:
JUNGLE.ensureSize(w, h)      // resize canvas
JUNGLE.advance(dt)           // manual frame step (testing)
JUNGLE.render()              // manual render (testing)
JUNGLE.setAlpha(a)           // cross-fade opacity
JUNGLE.start() / stop()      // rAF loop control
JUNGLE.suspend() / resume()  // pause without killing loop
JUNGLE.setForceEnergy(v)     // override energy for testing
JUNGLE.setTime(t)            // jump to time-of-day (0-1)
JUNGLE.setWeather(w)         // force weather state
JUNGLE.canvas()              // returns canvas element
JUNGLE.dbg()                 // returns debug state snapshot

4. ToneSync Module #

A self-contained IIFE that reads audio data from the player and computes morph targets for visual elements. Located inside the JUNGLE module scope.

Architecture

ToneSync.create(opts) → {
  metrics: {        // read-only public state
    energy, bassEnergy, midEnergy, highEnergy,
    beatPulse, beatFlag, beatRate,
    riverEnergy, rainEnergy, natureScore,
    flowerBoost, musicActive, isCityPop,
    freqBands[8]
  },
  morphs: {         // computed morph targets (0.7-2.2 range)
    treeH, treeW, mushroomH, mushroomW, templeH
  },
  update(dt, player),   // read audio, compute metrics
  tickTone(dt),         // compute morph targets from metrics
  reset(),              // clear all state
  setForceEnergy(v)     // override energy for testing
}

Adaptive Beat Detection

Algorithm

Tracks a rolling bass baseline (_bassBaseline) that adapts to quiet and loud tracks. A beat fires when bass exceeds both:

  1. Absolute minimum threshold (config.beatThreshold = 0.35)
  2. Adaptive threshold = baseline * beatRatio (catches relative spikes)
_bassBaseline += (bassEnergy - _bassBaseline) * beatBaselineLerp * dt;
var adaptiveThreshold = Math.max(config.beatThreshold, _bassBaseline * config.beatRatio);
if (curBass > adaptiveThreshold && curBass > _prevBass * config.beatRatio && _beatCooldown <= 0) {
  metrics.beatPulse = 1;
  metrics.beatFlag = true;
}

Nature Sound Detection

Uses sustained mid/high frequencies with bass + beat suppression:

  • River energy: sustained mid frequencies with low bass (water flow)
  • Rain energy: sustained high frequencies with low bass (broadband hiss)
  • Lerp rate 0.04 for responsive detection

5. Jungle Scene System #

4-Layer Cache System

The jungle uses a staggered refresh system to balance visual quality with performance:

LayerContentsRefresh IntervalBuffer
bgSky, stars, sun/moon, clouds, mountains, distant forest6 frames_bufs.bg
hillMossy hills, rocks, waterfall cliffs6 frames_bufs.hill
midMid-distance forest4 frames_bufs.mid
animGround, river, foreground, wildlife, weather FX2 frames_bufs.anim
Starvation Prevention: Any layer not refreshed in _STARVE=30 frames gets force-refreshed, bypassing the _maxRefresh=3 cap. This ensures the bg (sky) layer always updates even when hill is slow.

Scroll Speeds

var SPD = { far:0.02, midfar:0.05, mid:0.12, hill:0.18, near:0.30, ground:0.50 };

Per-Frame Music FX Overlay

To eliminate stop-motion animation, drawMusicFX() runs every frame on the composite canvas, drawing:

  • Tree rhythm glow (14 vertical light pillars)
  • Flower bloom sparkles (80 seeds)
  • Bass ground pulse
  • Temple morph glow
  • Temple monkeys (3-5 per temple, beat-synced bounce)
  • Disco spotlights (6 colored cones)
  • Disco pitfire gathering (gorillas, monkeys, gibbons)
  • Disco firefly sparks
  • Bat/bird gorilla spotlights

6. Performance Optimization #

Memory Management

TechniqueImplementation
HSL cache_hslCache with 6000-entry cap, auto-clears on overflow
Array reuse_riverCols, _freqBands, _ffPos mutated in place
Batch decayIdle metrics use grouped Math.pow calls (d1-d5) instead of per-metric
Color quantizationAlpha values rounded to 1/8 increments for fillStyle cache hits

Draw Call Reduction

  • Run batching: drawRiver batches consecutive columns with identical y-values into single fillRect calls (~5x reduction)
  • Culling: Off-screen elements skipped with sx < -W*0.2 || sx > W*1.2
  • Idle optimization: Music-only elements (panther chase, burning trees) skipped when no music; firefly count halved (15 vs 30)
  • Cache once: drawRiver caches skyStops() reflection color once per refresh
dt Cap: dt is clamped to [0.25, 3.0] to prevent death spiral when FPS drops. Without this, large dt causes all layers to refresh simultaneously, increasing frame time, increasing dt further.

7. Disco Ball Event System #

Trigger Conditions

  • CityPop music detected (P._isCityPop && P._cityPopJungle)
  • Night time (nightF > 0.40)
  • Music active
  • 60% trigger chance every ~10s (600 frames)
  • Active duration: 15-30 seconds (900-1800 frames)

Disco Pitfire Gathering

When the disco ball activates, _initDiscoPitfire() spawns a campfire gathering in the foreground:

Monkeys3-5P2*1.2Sit in circle, beat-synced bounce, animated tails

Bat Spotlight System

When bats fly over gorillas (dx < P2*8), they drop colored cone spotlights with pulsing ground pools. 6 cycling disco hues, beat-synced cone width.

8. Audio Coupling #

Data Flow

Player.update()
  → AnalyserNode.getByteFrequencyData()
  → P._freqBands[8]  (0-1 normalized)
  → P._energy, P._bassEnergy

JUNGLE.advance(dt)
  → ToneSync.update(dt, P)     // reads P._freqBands
  → ToneSync.tickTone(dt)      // computes morphs
  → advance() applies morphs to visual state

Audio-Driven Weather

_audioRainAccum accumulates when rainEnergy > 0.35:

  • 180 frames (3s) → forces rain weather transition
  • 300 frames (5s) → escalates to heavy_rain
  • Decays at 0.96/frame when rain stops
  • Override runs after _tickWeather to prevent flicker

Waterfall Flow Boost

var flowBoost = 1 + 0.6 * riverEnergy;   // width multiplier
var foamSpd = 2.6 * (1 + 2.0 * riverEnergy);  // foam speed (up to 3x)

10. Extending the Project #

Adding a New Animal

  1. Create _initNewAnimal() function that populates an array with position/phase data
  2. Create drawNewAnimal() function using fillRect pixel art
  3. Add the draw call to the anim layer refresh or drawMusicFX() for per-frame
  4. Cull off-screen: if (sx < -P2*20 || sx > W+P2*20) continue;
  5. Clear array on resize in ensureSize()

Adding a New Weather State

  1. Add the weather name to _JWTRANS array with valid transitions
  2. Add it to _IDLE_WEATHERS if it should appear during idle
  3. Add intensity helper function (e.g., function newWI() { ... })
  4. Add drawing logic in the appropriate layer's draw function

Adding a New Music FX Overlay

  1. Create drawNewFX(ctx) function with early-return guard
  2. Use ctx.save() / ctx.restore() for blend modes
  3. Add call in drawMusicFX()
  4. Use pre-allocated arrays for positions — never create per-frame

11. Hard Constraints #

The following constraints must never be violated:

  • No sprites: Jungle scene uses pixel art via fillRect only
  • No green in sun glow: Sun gradient is orange → white → sky blue → purple
  • No fireworks in rain: Rainy weather suppresses fireworks
  • No mammals on river: Jungle river has no swimming mammals
  • Mountains higher than buildings: Background mountains must always be taller
  • _hslCache cap: Must have 6000-entry cap with auto-clear
  • _loop must not stop: Resilient try-catch, always re-schedule rAF
  • _frameBudget BANNED: Time-budget scheduling causes bg layer starvation
  • Scene locked per-track: No mid-song transitions between citytone and universe
