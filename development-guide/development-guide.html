Architecture

CityTone is a single-file application (LaunchPulse.html) containing all HTML, CSS, and JavaScript. No build tools or external dependencies are required. The app auto-detects music style and switches between 3 scenes: CityTone (default), Universe (meditation), and Jungle (nature sounds). A standalone development file (jungle-dev.html) contains the latest jungle scene for iterative development.

Performance Guidelines

  • Cache gradients with cache keys to avoid recreating every frame
  • Use fillRect over arc where possible (rectangles are faster)
  • Limit particle counts and use early-exit conditions
  • Music-reactive values use _smoothEnergy with lerp for smooth transitions
  • Avoid creating objects inside the render loop

Color System

All colors use hsl(h,s,l) and hsla(h,s,l,a) helper functions. Night-aware rendering checks nf (nightFactor):

ctx.fillStyle=nf>0.5 ? hsl(220,8,22) : hsl(220,12,55);
// Dark version for night, lighter for day

Audio Response

The analyzer splits frequency data into 8 bands. Each building is assigned a band via (i + layer*7) % 8. The _smoothEnergy property on each building lerps toward the band energy for smooth animation:

var bandIdx=((i+li*7)&7);
var bandEnergy=bands[bandIdx];
b._smoothEnergy+=(bandEnergy-b._smoothEnergy)*0.35;
dynH=b.h*clamp(0.3+b._smoothEnergy*2.2, 0.3, 2.5);

Jungle Scene Architecture

The jungle scene runs as an independent IIFE module with its own rAF loop, decoupled from the CityTone player. When integrated in LaunchPulse.html, it reads audio data from the main player (P._freqBands, P._energy) instead of its own JUNGLE_AUDIO analyzer.

Jungle Render Pipeline

Layer bg (every 6 frames):
  drawSky → drawStars → drawSunMoon → drawClouds
  → drawMountains → drawMountainTrees → drawCliffMountains
  → drawTropicalMountains → drawAztecPyramids
  → drawFarForest → drawMidfarForest

Layer hill (every 3 frames):
  drawHills → drawHillArchitectures → drawWaterfallCliff

Layer mid (every 4 frames):
  drawMidForest

Layer anim (every 2 frames):
  drawGround → drawWaterfall → drawRiver → drawBeams
  → drawForeground → drawWeatherFX
  → drawGibbons → drawParrots → drawButterflies
  → drawCrocodiles → drawPantherChase → drawLitTree → drawFireflies

Composite (every frame):
  clear → drawImage(bg) → drawImage(hill) → drawImage(mid) → drawImage(anim)
  → golden hour overlay → music energy overlay → beat flash
